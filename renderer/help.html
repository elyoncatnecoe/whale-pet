📖 帮助

🖱️ 基本操作

左键拖动 移动桌宠窗口

左键单击 弹出派活输入框 + 互动泡泡

右键单击 打开菜单（换皮肤 / 跳舞强度 / 播放器 / 帮助）

右键拖动 旋转视角

🐟 互动

点击鲸鱼后，窗口左侧会出现三个互动泡泡：

🐟 喂食 → 小鱼游入鲸鱼嘴里

💗 爱心 → 冒出爱心，鲸鱼欢快扑腾

💤 睡眠 → 鲸鱼闭眼入睡（再点一次或点击鲸鱼唤醒）

🎨 换皮肤

右键菜单 → 换皮肤：深寻蓝 / 虎鲸黑 / 草莓粉 / 薄荷绿 / 土豪金，或选「自定义配色」用取色器自由搭配身体与肚皮颜色。

🎚 跳舞强度

右键菜单 → 跳舞强度：关闭 / 低 / 中 / 高，控制播放音乐时鲸鱼随节奏跳舞的活跃度。

🎵 播放器

右键菜单 → 播放器：导入本地音频，虎鲸会随节拍打点、偶尔转圈、头顶冒音符。

💬 派活

单击鲸鱼 → 输入一句话，虎鲸会把它派给 dsh harness 并流式回显结果。需先启动 dsh web（默认 http://127.0.0.1:3080）。
